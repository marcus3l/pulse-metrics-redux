# Pulse Metrics — dashboard de marketing

Protótipo de dashboard para acompanhar campanhas e indicadores de marketing. O projeto reúne telas de métricas, públicos, relatórios e equipe, com dados locais de demonstração.

## Destaques

- Visão geral de campanhas, métricas e audiência
- Gráficos, filtros, tabelas e relatórios
- Componentes de autenticação e gerenciamento de equipe
- Dados de exemplo e testes automatizados

## Tecnologias

React, TypeScript, Vite, Redux, Chart.js, Styled Components, Jest e Puppeteer. A pasta `api` contém um serviço em Go.

## Como executar

Requer Node.js e Go instalados.

```bash
npm install
npm run dev:full
```

O front-end e a API são iniciados juntos. Também é possível iniciar separadamente com `npm run dev` e `npm run api`. Execute os testes com `npm test`.

## Dados de demonstração

Os usuários e métricas são fictícios e servem apenas para demonstração local. Credenciais presentes nos testes não são contas reais.

## Contexto

Projeto educacional em evolução; esta pasta representa uma etapa específica do curso.
